# Assets

## What is here

| File | Use |
| --- | --- |
| `logo-sww-full.png` (940×1055) | Primary lock-up. Title slides, report covers, login screens. Min width 180px. |
| `logo-sww-emblem.png` (856×730) | Emblem + SWW monogram. Favicon, app icon, sidebar mark when collapsed. Min width 32px. |
| `logo-sww-wordmark.png` (940×325) | Horizontal wordmark. App top bar, slide footers, document headers. Min width 120px. |

All three are crops of the single supplied raster `uploads/sww-logo.png` — no marks were redrawn,
recoloured or reconstructed.

## Usage rules

- **Clear space**: minimum of the emblem's ring width on all sides; practically, 0.5× the wordmark's
  cap height. Nothing crosses the ring.
- **Background**: the supplied files have an **opaque white background**. On white or `--grey-25/50`
  surfaces place them directly. On navy or photography, place the logo inside a white card/pill with
  `--radius-md` and 12–16px padding — do **not** knock the white out (the wave and monogram contain
  intentional white counters that would break).
- **Never**: recolour, add effects, stretch non-proportionally, rotate, place on a busy photo without
  the white holder, or rebuild the wordmark in a live font.
- **Tagline** "ENERGIE FÜR UNSERE STADT" only appears as part of the full lock-up; it is never set
  separately in live type.

## Missing — please supply

1. **Vector logo** (SVG/AI/EPS) and a **transparent PNG**. The raster crops pixelate above ~500px and
   cannot be placed on dark surfaces without a white holder.
2. **Mono/one-colour variants** (all-navy, all-white) for print, fax, embroidery, dark UI.
3. **Brand photography** — port, substation, switchgear, Elbe. Slide covers currently ship as flat
   navy fields because no imagery exists in the sources.
4. **Licensed corporate typeface**, if one exists (system currently uses IBM Plex Sans/Mono).
5. **Icon library**, if one exists (system currently substitutes Lucide via CDN).
