# SWW-Assets

| Datei | Verwendung |
| --- | --- |
| `logo-sww-full.png` | Vollständiges Zeichen für Titelseiten |
| `logo-sww-emblem.png` | Kompakte Bildmarke |
| `logo-sww-wordmark.png` | Horizontale Wortmarke für Header und Fußzeilen |

Die Dateien sind unveränderte Ausschnitte des ursprünglich gelieferten Rasters.
Original: `brand/reference/uploads/sww-logo.png` im Repository.

Weißer Hintergrund ist Bestandteil der Dateien. Auf dunklen Flächen einen weißen Halter
verwenden; nicht strecken, umfärben oder die Wortmarke mit Text nachbauen.
Freiraum mindestens etwa eine halbe Versalhöhe der Wortmarke.

Offen sind ein offizielles SVG-/EPS-/PDF-Vektorlogo, transparente PNGs und einfarbige Varianten.
Es wurde kein künstliches Vektorlogo aus dem Raster abgeleitet.

Lokale Web-/Office-Fonts unter `../dist/fonts/`, Lizenzen unter `../dist/licenses/`.
IBM Plex Sans und Geist Mono werden verwendet. Die Lucide-Icons sind als lokale SVG-Masken
im Komponentenbundle enthalten. Alle Versionen sind über das npm-Lockfile festgeschrieben.
