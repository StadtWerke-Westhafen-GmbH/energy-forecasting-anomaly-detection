# HTML-Folienreferenzen

Zehn 1280 × 720 px große Layoutbeispiele, zusammen unter
`../templates/projekt-praesentation/index.html` sichtbar.

Die Beispielinhalte sind synthetisch. Für die eigene Präsentation die bearbeitbare
PPTX/POTX unter `brand/templates/presentations/` kopieren und unter `docs/` speichern.
Schriften, Farben und Diagrammregeln: [Präsentationsregeln](../guidelines/slides.md).

`slide.css` verwendet die zentralen CSS-Tokens. Fonts, Icons und Plotly werden lokal geladen.
