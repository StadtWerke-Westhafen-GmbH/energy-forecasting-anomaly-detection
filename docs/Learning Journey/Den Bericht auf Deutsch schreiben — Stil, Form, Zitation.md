# Den Bericht auf Deutsch schreiben — Stil, Form, Zitation

Ihr Bericht-Entwurf ist inhaltlich fertig: Ist-Zustand, ML Canvas, Sprint-Dokumentation, Workflow, Ergebnisse sind alle drin. Beim ersten Probelesen merken Sie aber: der Text wirkt zwischen den Kapiteln uneinheitlich, manche Formulierungen lesen sich umgangssprachlich, Quellenangaben sind mal mit Klammern, mal als Fußnoten. Vor der Abgabe muss das vereinheitlicht werden — sonst kostet das Punkte in der Kategorie „saubere Dokumentation".

Nach dieser Lektion können Sie:

-   die IHK-Formatvorgaben für den schriftlichen Bericht aufzählen (1,5-zeilig, 2,5 cm Ränder, Arial/Times 12 pt, 10–15 Seiten),

-   einen Absatz von umgangssprachlichem Englisch-Stil in formellen deutschen Wirtschaftston überführen.

_IHK-Formatvorgaben für den Bericht_

Die IHK gibt vier formelle Vorgaben, die Sie strikt einhalten müssen:

| Anforderung | Vorgabe |
| --- | --- |
| Zeilenabstand | 1,5-zeilig |
| Seitenränder | 2,5 cm an allen Seiten |
| Schriftart und -größe | Arial oder Times New Roman, 12 pt |
| Umfang | 10 bis maximal 15 Seiten (ohne Anhang, Literaturverzeichnis und Titelblatt) |

Die T2-Berichtsvorlage erfüllt diese Vorgaben — wenn Sie die Vorlage nutzen und nicht überschreiben, sind Sie automatisch konform.

| Element | Pflicht? |
| --- | --- |
| Titelblatt | Ja |
| Inhaltsverzeichnis | Ja (in Word automatisch generieren) |
| Abkürzungsverzeichnis | Ja, wenn Abkürzungen verwendet werden |
| Kapitel 1 — Ist-Zustand | Ja |
| Kapitel 2 — ML Canvas | Ja |
| Kapitel 3 — Projektplanung und SCRUM | Ja |
| Kapitel 4 — Workflow und Ergebnisse | Ja |
| Persönliches Fazit (in Kapitel 3) | Ja |
| Ausblick (in Kapitel 3) | Ja |
| Literaturverzeichnis | Ja |
| Anhang (Visualisierungen, Code-Auszüge) | Optional |

Der Bericht ist eine **professionelle Arbeit für eine fiktive Unternehmensführung**. Ton: sachlich, präzise, höflich-formell, ohne Werbung.

-   Passiv-Konstruktionen, wenn das Subjekt unwichtig ist: _„Die Daten wurden auf Duplikate geprüft."_

-   Sachliche Beschreibung: _„Bei der Analyse zeigte sich eine Korrelation von 0,42."_

-   Klare Begründungen: _„Wir wählten Median-Imputation, weil die Verteilung schief war."_

-   Umgangssprache: _„Da haben wir gemerkt, dass…"_ → besser: _„Es zeigte sich, dass…"_

-   Werbe-Sprache: _„Unser außergewöhnliches Modell"_ → besser: _„Das vorgestellte Modell"_

-   Übertreibungen: _„Unfassbar gute Ergebnisse"_ → besser: _„Solide Ergebnisse mit ROC-AUC = 0,72"_

-   Erste-Person-Ausbrüche: _„Wir fanden das super interessant!"_ → besser: _„Diese Erkenntnis war für die Gruppe lehrreich."_

-   Smiley- oder Ausrufezeichen-Inflation.

| Kontext | Empfehlung |
| --- | --- |
| Methodisches Vorgehen | Wir-Form oder Passiv: „Wir haben die Daten bereinigt" / „Die Daten wurden bereinigt" |
| Persönliches Fazit (Kapitel 3.6) | Ich-Form: „Ich habe gelernt, dass die Wahl der Metrik bei imbalanced classes oft schwieriger ist als das Modell selbst." |
| Beschreibung der Organisation | Drittperson: „Die NordWind Shop GmbH beschäftigt 120 Mitarbeitende." |

Die IHK verlangt einen **Kurzquellbeleg im Text** plus ein **Literaturverzeichnis am Ende**.

| Quellenart | Format |
| --- | --- |
| Buch / Zeitschrift | `(Autor, Jahr, Seite)` — z. B. `(Lemanzyk, 2020, S. 23)` |
| Webseite / Online-Dokument | `[URL, abgerufen Monat Jahr]` — z. B. `[<https://www.dihk-bildungs-gmbh.de/>..., abgerufen Monat Jahr]` |

Alphabetisch nach Autor sortiert. Vollständige Quellenangabe:

> Lemanzyk, S. (2020). _Data Analyst (IHK) — Konzept Plus_. DIHK-Bildungs-GmbH, Bonn. K181/1/1.
> 
> DIHK-Bildungs-GmbH. (Jahr). _Data Analyst (IHK) — Online-Zertifikatslehrgang_. Verfügbar unter: [https://www.dihk-bildungs-gmbh.de/](https://www.dihk-bildungs-gmbh.de/)... \[abgerufen Monat Jahr\].

**Konsistenz schlägt Perfektion.** Wählen Sie einen Stil (z. B. APA-light) und halten Sie ihn durchgehend.

Wenn Sie eine Abkürzung **häufiger als zweimal** verwenden, gehört sie ins Abkürzungsverzeichnis. Bei der ersten Verwendung im Text führen Sie sie ein:

> _„Im Customer Relationship Management (CRM) werden …"_

Danach nutzen Sie die Abkürzung frei.

Typische Abkürzungen im IHK-Bericht:

| Abkürzung | Bedeutung |
| --- | --- |
| CRM | Customer Relationship Management |
| EDA | Exploratory Data Analysis |
| ETL | Extract, Transform, Load |
| KPI | Key Performance Indicator |
| ML | Machine Learning |
| ROC-AUC | Receiver Operating Characteristic — Area Under Curve |

Auf Deutsch gibt es ein paar Konventionen, die in englischsprachigen Berichten oft fehlerhaft umgesetzt werden:

-   **Dezimal-Komma**, nicht Punkt: `0,72` (nicht `0.72`)

-   **Tausender-Punkt** oder schmales Leerzeichen: `1.234.567` oder `1 234 567` (nicht `1,234,567`)

-   **Prozentzeichen mit schmalem Leerraum**: `83 %` (nicht `83%`)

-   **EUR oder €**: einheitlich, z. B. `190.000 EUR` oder `190.000 €`

-   **Datums-Format**: `31.12.2025` oder `31. Dezember 2025` (nicht `12/31/2025`)

-   **Inkonsistenter Stil zwischen Kapiteln** — jede Person hat ihr Kapitel selbst geschrieben, niemand hat redaktionell durchgesehen. Lösung: am Ende des Sprints 3 schickt eine Person den ganzen Bericht durch und glättet Stil und Übergänge.

-   **Pluralfehler**: _„Die Datenset hat 10.000 Zeilen"_ (richtig: _„Der Datensatz hat 10.000 Zeilen"_).

-   **Anglizismen-Inflation**: _„Wir haben den Workflow gepowered und das Result deployed"_ → besser auf Deutsch.

-   **Quellenangaben vergessen** oder nur teilweise (Autor ja, Seite nein).

-   **Persönliches Fazit in Wir-Form**, statt individuell.

-   **Zu lange Sätze** mit drei Nebensätzen — typisch deutscher Stilfehler im Wirtschaftston.

Lesen Sie den Bericht laut, in einem Durchgang. Fragen Sie sich:

1. Gibt es Abschnitte, wo Ihre eigene Stimme an einer Stelle deutsch und an einer anderen englisch-formuliert klingt?

2. Steht für jede Zahl die Einheit?

3. Ist jede Quelle zitiert?

4. Ist das Abkürzungsverzeichnis vollständig?

5. Sind die Margins, die Schrift und der Zeilenabstand konform?

6. Beträgt der Umfang 10–15 Seiten Hauptteil?

Wenn Sie alle sechs mit Ja beantworten, ist der Bericht abgabefertig.

Lesen Sie den fertigen Text einmal laut — die meisten Stilfehler hören Sie sofort. In der nächsten Lektion: wie Sie diesen Inhalt in 30 Minuten Präsentation + 15 Minuten Live-Demo überführen.
